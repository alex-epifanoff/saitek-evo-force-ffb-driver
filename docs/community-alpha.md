# Experimental-alpha eligibility and limits

Version `0.1.0-alpha.2` targets the Saitek Cyborg Evo Force USB `06A3:FFB5` with the already validated HID PID descriptor, x64 Windows DirectInput, and the exact software identities in [README](../README.md). A similar product name or matching USB ID alone is insufficient: the runtime rejects incompatible report geometry and pool layout when an application intentionally opens it.

Check is passive and does not open the device. `Hardware.Device`, `Hardware.Descriptor`, and `Hardware.Forces` therefore say `NotChecked`; this is not a detection failure or a compatibility approval. Software checks are not a fresh physical test. An unsupported Windows DirectInput hash refuses Apply without changing registration. The optional launcher also fails closed on changed Bridge/.NET/CoreLib identities. Do not bypass these guards to try another version.

The owner reports that FFB works in X-Plane 12 on their setup. The exact artifact and individual effects behind that report have not been established. Earlier observations include useful centering during flight at 70/70 pitch/roll. A later 40% vibration adjustment had no confirmed improvement at that time. These numbers are historical observations, not settings installed by the package or recommended starting strengths.

Open acceptance items include validation of this extracted package, satisfactory physical texture, individual periodic-force behavior, successful unplug/replug recovery and clean second-PC setup. There is no automatic reconnect or replay of effects. Disarm, fully exit Bridge, resolve the connection, and start a fresh session before deliberately Arming again. Aircraft/profile changes may disarm Bridge; review the new profile before rearming.

No service, account, remote updater, telemetry or network upload is included. A local support report includes only constrained software versions/hashes, registration booleans and transaction marker counts. It excludes SID, account/computer name, serials, raw paths/errors, registry trees and backup content. Review it before voluntarily sharing it in a [GitHub issue](https://github.com/alex-epifanoff/saitek-evo-force-ffb-driver/issues). Include the release version, the Check result, a short reproduction and whether the problem concerns input, installation, launch or forces. Keep registry backups and raw logs private.

This alpha is unsigned. Project code uses the [MIT License](../LICENSE); third-party materials retain their own terms. Static MSVC runtime redistribution review remains open before maintainer publication. The package notices record these limits. Neither a green CI run nor an unsigned SHA-256 manifest establishes third-party redistribution clearance, publisher authentication or wider hardware support.
