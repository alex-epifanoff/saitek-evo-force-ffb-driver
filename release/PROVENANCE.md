# Provenance of the experimental alpha

The runtime consists of original project source: `native/SaitekFfbDriver.cpp`, `native/HidPidDevice.cpp`, `native/HidPidDevice.h` and `native/SaitekFfbDriver.def`. Original installation, transaction, build, user tools and offline test inputs accompany the source archive through an exact file allowlist. The production DLL compiles the DirectInput adapter and HID transport; it neither incorporates nor loads the legacy vendor effect DLL or saved Linux driver.

The implementation uses Windows SDK contracts and observed exact-device HID PID geometry. The published [zanppa/hid-pidff revision 37709a8efa76bef8bd82d2b89b478019700ecaff](https://github.com/zanppa/hid-pidff/tree/37709a8efa76bef8bd82d2b89b478019700ecaff), identified as GPL-2.0-or-later research, informed behavior decisions such as host allocation, the separate Set Effect table and initialized envelopes. Engineering review found no copied/adapted Linux implementation in the runtime. This is a bounded assessment, not proof of ownership or legal clearance; further provenance review remains open.

The source archive includes the immutable `release/import-origin.json`. It records the historical source import's commit and file inventory before public-repository changes. Its historical hashes are expected to differ from subsequently edited files. It is **not the current checkout identity or current build evidence**, must not be rewritten to match later changes, and is excluded from the binary archive. Each source export's generated `source-identity.json` and the release manifest provide the current release's source identity. The local build manifest records the current source/test hashes and native build results.

The original probe and `HidTrace` are excluded from both archives, along with their build helper and guides. Legacy tracing contains embedded vendor/community-patch instruction bytes, private layout offsets and instrumentation. No assertion about rights to those signatures is needed for this exclusion. The vendor-dependent repair route is retained outside this repository for historical rollback and is not shipped.

Also excluded: proprietary Saitek DLL/SYS/INF files and binary patches; GPL research source/descriptor copies; specification PDFs; Bridge and .NET assemblies/installers; X-Plane files; Windows DLLs; compiler/SDK headers, tools and import libraries; diagnostic executables; private logs, screenshots, dumps, configuration, registry backups and account/device identifiers. Archives do not recursively export development output or internal planning materials.

The DLL uses MSVC `/MT`, statically incorporating compiler runtime code, and links SDK `dxguid.lib`, `ole32.lib` and `hid.lib`. The release manifest records compiler/SDK identity, command context and source inventory hash. Original driver source does not mean the binary contains no third-party code. Review of the applicable Microsoft toolchain redistribution terms remains open; see [Microsoft guidance](https://learn.microsoft.com/en-us/cpp/windows/redistributing-visual-cpp-files?view=msvc-170).
